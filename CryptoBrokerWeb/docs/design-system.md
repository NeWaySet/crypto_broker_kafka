# CryptoBroker: дизайн-система и структура интерфейса

## Цель

Интерфейс сделан как рабочий secure-мессенджер, а не как лендинг. Главный сценарий: пользователь входит, ищет другого пользователя по username, создает чат, отправляет сообщение и может посмотреть технический криптоконтейнер.

## Визуальный принцип

Выбран грубый технический стиль:

- четкие границы вместо мягких декоративных карточек;
- маленькие скругления;
- плотные панели;
- акцентный синий только для активных элементов;
- минимум визуального шума;
- светлая и темная тема через CSS-токены.

Такой стиль лучше подходит для проекта по защите информации: интерфейс выглядит как рабочий инструмент, а не как рекламная страница.

## Токены

Основные CSS-переменные:

| Токен | Назначение |
| --- | --- |
| `--bg` | общий фон приложения и области сообщений |
| `--surface` | основные панели: sidebar, header, modal |
| `--surface-2` | вторичный фон: поля, composer, меню |
| `--surface-3` | hover/selected фон |
| `--text` | основной текст |
| `--muted` | подписи, время, статус |
| `--line` | границы и разделители |
| `--accent` | активные действия, выбранные вкладки |
| `--danger` | опасные действия |
| `--success` | онлайн/успех |
| `--bubble-in` | входящие сообщения |
| `--bubble-out` | исходящие сообщения |

## Компоненты

| Компонент | Роль |
| --- | --- |
| `AuthScreen` | вход и регистрация по username/паролю |
| `Sidebar` | профиль, меню, поиск, фильтры, список чатов |
| `ChatSearch` | единая строка поиска |
| `ChatFilters` | фильтры списка чатов |
| `ChatListItem` | строка чата |
| `ChatWindow` | активная переписка |
| `MessageBubble` | сообщение, реакции, действия |
| `MessageComposer` | ввод текста, ответ, редактирование, вложения |
| `ChatInfoPanel` | профиль чата, участники, файлы, криптоконтейнер |
| `EmptyState` | пустые состояния: нет чатов, нет сообщений, не найден пользователь |
| `SettingsModal` | настройки профиля и темы |

## Сценарии экранов для Figma

Для Figma-файла достаточно собрать восемь экранов:

1. Вход.
2. Регистрация.
3. Пустой список чатов.
4. Поиск пользователя по username.
5. Активный чат.
6. Пустой чат.
7. Правая панель “Крипто”.
8. Мобильная версия активного чата.

## Почему так

Главное отличие от обычного демо-мессенджера в том, что интерфейс показывает не только переписку, но и техническую сторону защиты. Поэтому вкладка “Крипто” является частью продукта: она демонстрирует `algorithm`, `iv`, `ciphertext`, `authTag` и `metadata`.
