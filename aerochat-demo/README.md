# AeroChat Demo

Безопасный локальный демо-мессенджер на React + TypeScript.

- Не использует Telegram API.
- Не копирует Telegram Web.
- Не запрашивает номер телефона, коды, пароли или реальные аккаунты.
- Все данные демонстрационные и хранятся локально в `localStorage`.

Запуск:

```powershell
npm install
npm run dev
```

Адрес:

```text
http://localhost:5174
```
